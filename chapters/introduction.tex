\section{Introduction}
% Start with digital nature
The use of digital natural landscapes is common in a number of different application. Video games have created many landscapes wherein the player is immersed, with varying levels of realism, but even outside of entertainment digital nature can be used for more serious applications. In previous research, it has been shown that digital nature has a positive effect on mental and social wellbeing \cite{van_houwelingen-snippe_feeling_2020}, and can function as a substitute for real natural environments when these are not available. In previous research into the effect of digital nature, most environments have been hand-crafted by a designer. The process of creating these environments can be time consuming and have to be done each time a different environment needs to be created.

% Go into PCG as a solution
Instead of manually designing virtual environments, Procedural Content Generation (PCG) can be used to automatically generate certain aspects of the desired terrain and can reduce or remove the workload necessary for generating realistic virtual environments. When generating terrain, one important aspect is the trade-off between the control the user has over the generated terrain against the amount of effort required to create the terrain. This thesis will analyse the parameters regularly used in the generation of procedural environments, and what effect the parameters have on the system. To accomplish this, we have designed a system capable of generating environments containing a number of terrain features often found in nature environments. This system aims to generate digital landscapes that are aimed to be viewed primarily from a single point of view. In addition to creating these environments, we have looked at multiple criteria of the resulting landscape to find qualitative evaluations of the generated terrain.

% Talk about the implementation in unity
We have created an implementation of the system in the Unity game engine\footnote{Unity Real-Time Development Platform. From https://unity.com/}. Unity is a widely used game engine for its ease of use, and is already used in other tools and programs designed to use digital nature environments.
